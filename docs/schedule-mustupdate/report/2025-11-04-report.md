## Technical Highlights

### 1. Thread-Safe Database Access
**Implementation**: `core/database.py`

```python
import threading

_connections = threading.local()

def get_db_connection(db_path=None):
    """Each thread gets its own connection"""
    if not hasattr(_connections, 'conn'):
        _connections.conn = sqlite3.connect(db_path or DB_PATH)
    return _connections.conn
```

**Benefits**:
- Prevents "database is locked" errors
- Safe for Flask's threaded mode
- Automatic connection pooling per thread

### 3. Risk Scoring Algorithm
**Implementation**: `services/risk_service.py`

**Composite Score Calculation**:
```python
severity_score = (
    keyword_score * 5.0 +       # High-risk keywords
    user_impact_score * 3.0 +   # Multi-user impact
    escalation_score * 2.0      # Escalation detected
)

frequency_score = (
    config_item_freq * 5.0 +    # Config item frequency (0-1)
    role_component_freq * 3.0 + # Role frequency (0-3)
    time_cluster_score * 2.0    # Time clustering (1-3)
)

impact_score = sqrt(severity_score^2 + frequency_score^2)
```

**Adaptive Risk Levels (KMeans)**:
- Automatically adjusts thresholds based on data distribution
- Requires: ≥4 records, range ≥5.0, stddev ≥3.0
- Falls back to fixed thresholds if criteria not met
