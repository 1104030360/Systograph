```python
save_query_context(
```

```json
}
```

**更新機制**:

## 🎯 設計方法論

### 設計原則: Linus Torvalds 工程哲學
1. **簡單直接** - 避免過度設計, 選擇最簡單能用的解決方案
2. **務實優先** - 先讓系統能動, 再優化細節
3. **明確邊界** - 清楚定義每個模組的責任與介面
4. **漸進演化** - 支持未來擴展, 但不預先實作用不到的功能
5. **效能實在** - 關注實際瓶頸, 不做無謂優化
6. **可測性** - 設計要讓測試容易執行

### 設計流程
1. **現況分析**: 識別技術債與改進空間
2. **架構設計**: 建立分層架構 (API/Services/Repositories)
3. **資料設計**: 確認Schema與索引結構 (保持向後相容)
