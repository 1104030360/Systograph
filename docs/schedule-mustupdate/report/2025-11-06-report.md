## 🛠️ 技術細節

### 使用的測試技巧
1. **tmp_path fixture**: 使用臨時目錄測試檔案 I/O
2. **unittest.mock.patch**: Mock builtins.open 測試 I/O 錯誤
3. **pytest.raises**: 驗證異常拋出
4. **SQLite in-memory**: 測試資料庫操作（base_repository）
5. **Integration tests**: 驗證跨實例的配置持久化

### 發現並修復的問題
1. **ValidationError 屬性名稱**:
   - 問題: 測試使用 `error_code`，實際是 `code`
   - 修復: 統一使用 `exc_info.value.code`

2. **Missing keys 處理**:
   - 問題: 測試預期拋出錯誤，但 `.get()` 返回 0
   - 修復: 調整測試預期為成功（1.0 + 0 = 1.0）
