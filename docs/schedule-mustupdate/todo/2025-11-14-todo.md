### 雲端 Ollama 呼叫方式
```python
from ollama import Client
import os

# 初始化雲端 Ollama Client
client = Client(
    host="https://ollama.com",
    headers={'Authorization': 'Bearer ' + os.environ.get('OLLAMA_API_KEY')}
)

# 發送請求 (支援 streaming)
messages = [
    {
        'role': 'user',
        'content': 'Why is the sky blue?',
    },
]

for part in client.chat('gpt-oss:120b', messages=messages, stream=True):
    print(part['message']['content'], end='', flush=True)
```

### 三層 Fallback 架構
1. **第一層 (雲端 Ollama)**: `gpt-oss:120b` via `ollama.Client(host="https://ollama.com")`

   - 失敗條件: API key 無效、網路錯誤、服務不可用

2. **第二層 (Power Automate AI Builder)**: 當前已實作
   - 優點: 企業級穩定性、已整合
   - 失敗條件: Webhook timeout、配額用盡

3. **第三層 (地端 Ollama)**: 當前已實作
   - 優點: 完全離線、無外部依賴
   - 模型: llama3.2, deepseek-coder-v2, command-r7b, phi3, orca2
