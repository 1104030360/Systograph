# Phase1 Dev Prompt: Viewer Frontend Foundation

請建立 Epic 1 Viewer 的前端基礎。

## 任務

- 使用 React + Vite + TypeScript。
- 使用 pnpm。
- 加入 React Flow、ELK、Zustand、TanStack Query、Zod、Lucide。
- 讀取 Timmy 提供的 `frontend-json-sample.json`。
- 建立 macOS-like local web app shell。
- 前端不得重新掃描 repo。

## 驗收

- `pnpm run dev` 可啟動。
- `pnpm run lint` 通過。
- `pnpm run build` 通過。
- Viewer 可在 Sample mode 顯示基本 shell。
