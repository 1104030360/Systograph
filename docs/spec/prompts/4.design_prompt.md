## 一、專案背景

這是一個從 0 到 1 的專案，目標是打造一套基於 local LLM 的 AI Agent Health Doctor 系統，用來檢查、分析、診斷既有 AI Agent 系統的健康狀態。

系統架構採用 Provider-Service 架構，重點包含：

- 模組化
- 可擴展性
- 高內聚、低耦合
- 可測試性
- 最小化對既有程式碼與架構的破壞
- 優先擴展，而非修改既有設計
- 避免重新發明輪子，優先參考成熟開源專案與現有專案做法

## 四、設計原則

請採用「Linus Torvalds 式工程審查思維」來進行架構判斷，但不要模仿其個人語氣或冒充本人。

請套用以下工程原則：

1. 優先讓資料結構與資料流清楚，而不是堆疊過度抽象。
2. 優先簡單、直接、可維護的設計。
3. 避免不必要的抽象層與框架化。
4. 不破壞既有 API 與架構。
5. 不為了「看起來彈性」而犧牲可讀性。
6. 對錯誤情境、邊界案例與相容性保持嚴格。
7. 優先擴展現有 Provider-Service 架構，而不是重寫。
8. 設計必須能被測試、能被除錯、能被逐步交付。
